# 5457 Travel Plan 🧭

個人旅行行程，手機優先的靜態網站（HTML + CSS + JS，無需安裝任何套件）。格式參考 [Travel_Plan](https://github.com/Ashur5457/Travel_Plan)。

## 🌏 行程

| 目的地 | 日期 | 行程 |
| --- | --- | --- |
| 🍁 關西紅葉 → 橫濱電池討論會 | 2026/11/22–24 | [kansai-1122/](kansai-1122/) |

## ✨ 功能

- 📱 手機單欄閱讀、日期分頁固定在頂端
- 🕒 依東京時間自動打開「今天」，並標出「現在」的行程
- 🗺️ 每個地點一鍵開 Google Maps
- ✅ 行前清單（只存在本機瀏覽器）

## 🚀 更新方式

行程資料都在各資料夾的 `app.js` 最上方 `days` 陣列；新增旅行就建一個新資料夾，再到根目錄 `index.html` 加入入口。

GitHub Pages：**Settings → Pages → Deploy from a branch → `main` / `(root)`**。

> 不放預約號碼、姓名等個資。時間為規劃時段，請以當日公告為準。
